## 一、接口设计（阶段 A 的核心产出）

### 1.1 关键裁剪（本轮调研结论）

canvasStore 方法分三层，工程视图只需要其中一层：

| 层 | 方法 | 工程视图是否需要 |
|:--|:--|:--|
| 画布管理 | loadCanvases/openCanvas/createCanvas/renameCanvas/deleteCanvas | 否（工程视图是单一实例，非多画布） |
| 生成运行时 | generateImage/cancelGeneration/genProgress/bindCanvasEvents | 否（生成类 body 不进工程作用域，工程节点不渲染它们） |
| **几何层** | nodes/connections/groups/createNode/updateNode/deleteNode/saveLayout/commitLayout/connect/rewire/deleteConnection/setViewport | **是——唯一抽象面** |

→ 阶段 A 只抽象几何层；生成运行时与画布管理留在自由画布作用域不动。
→ nodes body 中 GenImageBody/CollectionBody/SaveMediaBody/VideoToolBody/
  genRuntime/saveRuntime/videoToolRuntime 的 store 直连**不动**（自由画布
  专属 body）；只有**两画布共用**的 NoteBody（便签）需要 ctx 化。

### 1.4 节点作用域（两作用域完全互斥，用户定案）

- `NodeDefinition` 增加 `scope: "free" | "project" | "both"`（缺省 free；
  便签 = both，两画布共用）；
- **互斥规则**：工程视图**不可加载**自由画布节点，自由画布**不可加载**
  工程节点——
  - 建节点菜单按当前实例作用域过滤（工程实例只出 project+both，
    自由画布只出 free+both）；
  - 文件拖入分发、摘线到空白建节点菜单同样过滤；
  - 双保险：provider 拒收未知类型（注册表查询天然拦截，工程实例
    查不到 free 类型）；
- 工程节点 defs 位于 `CanvasPage/nodes/project/`，与自由画布节点同体系；
- 节点 chrome（NodeShell/端口行/手柄/提示）全部走自由画布现体系。

### 1.2 CanvasDataCtx 接口（新建 `CanvasPage/dataContext.tsx`）

```ts
interface CanvasNodeRecord { id: string; type: string; x: number; y: number;
  width: number | null; height: number | null; }
interface CanvasDataApi {
  // 读
  nodes(): CanvasNodeRecord[];
  connections(): CanvasConnectionRecord[];
  groups(): NodeGroup[];
  // 节点几何与内容
  createNode(type: string, x: number, y: number): void;
  updateNode(id: string, patch: Partial<CanvasNodeRecord>): void;
  deleteNode(id: string): void;
  saveLayout(items: { id; x; y; width?; height? }[]): void;   // 拖动中防抖
  commitLayout(items): void;                                   // 松手落盘
  // 连线
  connect(from: string, to: string, toPort?: string): void;
  rewire(connectionId: string, to: string): void;              // 摘线换目标
  deleteConnection(id: string): void;                          // 切线
  // 组与视口
  setGroups(groups: NodeGroup[]): void;
  setViewport(v: { x: number; y: number; k: number }): void;
}
```

- 默认实现 `storeCanvasData`：逐方法转发 canvasStore（**行为零变化**）；
- Provider + `useCanvasData()`；FreeCanvas 顶层取值注入，下游一律
  `useCanvasData()` 消费。

### 1.3 工程 provider 的语义映射表（阶段 B/C 施工图）

| CanvasDataApi | 工程实现（ProjectCanvasShell 内） |
|:--|:--|
| nodes | overview 派生：镜头卡(shot:)+资料(info:)+片段(segment:)+成片(output)+纸片(script:/prompt:)；位置=工程表 canvas_x/y + infoNodePos/segPos（按集 localStorage） |
| connections | node_links（端口级，to_port 六口）+ 生成链推导线（gen_from_asset） |
| createNode | 按 type 分流：note→addNote；segment→addSegment；entity 占位→addEntityPh；纸片→addScriptPh/addPromptPh |
| updateNode/saveLayout/commitLayout | 位置：persistCards/persistSegments/persistInfoOffsets/persistSizes（按集 localStorage + 工程表 canvas_x/y，各归其主） |
| deleteNode | removeSegment/removeInfoEntity/removeScriptPh/removePromptPh/删镜头 |
| connect/rewire/deleteConnection | linkNode/unlinkNode + displacePortLinks（顶掉）+ owner_key/组认领 |
| groups | nodeGroups（Ctrl+G，现状沿用） |
| setViewport | useCanvasView.saveView（按集 localStorage 现状） |
